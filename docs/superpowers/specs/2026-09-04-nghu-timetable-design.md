# Архитектурная спецификация: Приложение расписания НГХУ (Android + Backend)

## 1. Введение и цели проекта

Проект представляет собой мобильное приложение для студентов и преподавателей ГАПОУ НСО «Новосибирское государственное художественное училище (колледж)» (НГХУ).
Приложение решает проблему неудобного просмотра расписания, публикуемого на официальном сайте `https://nghu.ru/students/timetable/` в виде сложных PDF-таблиц.

Интерфейс и пользовательский опыт (UX) вдохновлены популярным студенческим приложением **«Кампус»**:
- Четкое разделение по группам с запоминанием выбора пользователя;
- Удобный поиск и просмотр занятости аудиторий (с разделением по корпусам: Главный корпус на Красном пр-те, 9 и корпус на ул. Спартака, 12);
- Поиск расписания по преподавателям;
- Живой индикатор текущей пары (с таймером до конца пары/перерыва);
- Офлайн-доступность (кеширование расписания локально на устройстве).

## 2. Архитектура системы

Система построена по клиент-серверной схеме в рамках одного монорепозитория:

```
nghuapp/
├── server/                 # Сервис парсинга расписания и REST API (Node.js / Express)
│   ├── src/
│   │   ├── parser/         # Загрузка страницы, скачивание PDF, координатный разбор ячеек
│   │   ├── models/         # TypeScript-типы расписания, групп, аудиторий, преподавателей
│   │   ├── routes/         # REST API эндпоинты (/api/schedule, /api/groups, /api/rooms, /api/teachers)
│   │   └── index.ts        # Точка входа сервера и планировщик автообновления
│   └── package.json
│
└── android/                # Нативное Android-приложение (Kotlin + Jetpack Compose)
    └── app/
        ├── src/main/java/ru/nghu/timetable/
        │   ├── data/       # Retrofit сетевой слой, Room локальная база данных, репозитории
        │   ├── domain/     # Модели предметной области и Use Cases
        │   └── ui/         # Jetpack Compose экраны (Расписание, Аудитории, Преподаватели, Темы)
        └── build.gradle.kts
```

## 3. Бэкенд и модуль парсинга (`server/`)

### 3.1. Алгоритм парсинга PDF
1. **Скрапинг:** Сервер запрашивает страницу `https://nghu.ru/students/timetable/`, парсит HTML и находит актуальную ссылку на файл (формат URL: `...admin-ajax.php?action=wpfd&task=file.download...` или прямая ссылка на `.pdf`).
2. **Извлечение метаданных:** Из названия файла и заголовка страницы извлекается период (например: *«на 04/05.09.2026 г.»*) и учебный семестр.
3. **Разбор страниц и координатной сетки:**
   - Каждая страница PDF содержит расписание для определённого набора групп (например, Стр. 1: 1–2 курсы `Ж-11`..`Д-24`, Стр. 2: 3–4 курсы `Ж-31`..`Д-43`, `Т-31`).
   - По горизонтальным координатам $X$ определяются границы колонок учебных групп.
   - По вертикальным координатам $Y$ определяются блоки дней недели (например, «пятница», «суббота») и строки звонков (пары с 9:00 до 17:55).
4. **Нормализация данных ячеек:**
   - Текст внутри ячейки разбивается на предмет, аудиторию и преподавателя.
   - Определение корпуса: если в тексте встречается строка «Спартака, 12» или номер кабинета вида «№216», аудитории присваивается статус корпуса *«ул. Спартака, 12»*; обычные номера (например, «109», «205», «103») относятся к *«Главному корпусу (Красный пр-т, 9)»*.
   - Двойные уроки (например, две пары подряд одного предмета) объединяются в логические блоки.

### 3.2. REST API Контракт
- `GET /api/schedule`
  - Параметры запроса (опционально): `group` (например, `Д-11`), `date` (например, `2026-09-04`).
  - Ответ: Полный объект расписания со списком дней, уроков и метаданными обновления.
- `GET /api/groups`
  - Ответ: Массив групп, сгруппированных по курсам (1, 2, 3, 4) и отделениям (Живопись, Дизайн, Театральное).
- `GET /api/rooms`
  - Параметры: `building` (опционально: `main`, `spartaka`).
  - Ответ: Список кабинетов, их расписание на текущую дату и статус занятости на текущий момент (свободен / занят группой X до времени Y).
- `GET /api/teachers`
  - Ответ: Список преподавателей, список их дисциплин и расписание занятий во всех группах.
- `POST /api/refresh`
  - Принудительный запуск парсера для проверки новых файлов на сайте.

## 4. Архитектура Android-приложения (`android/`)

### 4.1. Технологический стек
- **Язык:** Kotlin 2.0+
- **UI Toolkit:** Jetpack Compose с Material 3 (Material You, Dynamic Color)
- **Архитектура:** MVVM + Clean Architecture + Unidirectional Data Flow (StateFlow)
- **Сетевой клиент:** Retrofit 2 + OkHttp 4 + Kotlinx Serialization Converter
- **Локальное хранилище:**
  - Room (SQLite) для кеширования расписания групп, аудиторий и преподавателей
  - DataStore Preferences для настроек (выбранная группа по умолчанию, тема оформления)
- **Навигация:** Jetpack Navigation Compose

### 4.2. Офлайн-стратегия (Offline-First)
- При запуске приложение мгновенно считывает сохраненное расписание из Room DB и отображает его пользователю без ожидания сети (0 мс задержки).
- Параллельно в фоне запускается корутина проверки обновлений на сервере.
- Если получены новые данные, они атомарно обновляются в Room, и UI реактивно перерисовывается.
- При отсутствии сети или ошибке отображается ненавязчивый индикатор «Офлайн-режим (показано сохранённое расписание)».

## 5. Дизайн интерфейса (UI/UX в стиле «Кампус»)

### 5.1. Нижняя панель навигации (Bottom Navigation Bar)
1. **Расписание** (`Icon: CalendarToday`)
2. **Аудитории** (`Icon: MeetingRoom / Domain`)
3. **Преподаватели** (`Icon: Person / School`)

### 5.2. Экран «Расписание»
- **TopBar:**
  - Крупный селектор группы: плашка с текущей группой (например, `Д-11 ▾`), при тапе открывающая удобную шторку (BottomSheet) выбора группы с быстрым поиском.
  - Иконка ручного обновления и бейдж статуса синхронизации.
- **Горизонтальный селектор дней:**
  - Лента дней недели с числами и днями (например: `ПТ 04`, `СБ 05`).
  - Текущий день выделяется акцентным цветом и бейджем «Сегодня».
- **Виджет текущей пары (Live Widget):**
  - Во время учебных часов в верхней части экрана отображается информационный баннер:
    *«Сейчас: Живопись (каб. 109) • До конца пары 20 минут»* с плавной полосой прогресса.
  - Во время перерыва: *«Перерыв до 13:00 • Осталось 15 минут»*.
- **Карточки занятий (`LessonCard`):**
  - Левая колонка: Время звонков (`09:00 – 10:35`), номер пары (`1 пара`), таймлайн-линия с точкой статуса (завершена / идёт сейчас / предстоит).
  - Тело карточки:
    - Цветная полоса категории предмета (живопись/рисунок, спец. дизайн, общеобразовательные).
    - Крупное название дисциплины.
    - ФИО преподавателя с аватар-иконкой.
    - Бейдж аудитории:
      - Серо-синий бейдж для Главного корпуса: `каб. 109 (Красный пр-т, 9)`.
      - Контрастный оранжевый бейдж для выездного корпуса: `каб. 216 (ул. Спартака, 12)` — предотвращает путаницу со зданиями.
  - Разделители перерывов: карточка с указанием длительности перерыва между парами.

### 5.3. Экран «Аудитории»
- Поле быстрого поиска по номеру кабинета.
- Фильтр-чипы по корпусам: `Все`, `Главный (Красный пр-т, 9)`, `Спартака, 12`.
- Карточка аудитории:
  - Номер кабинета и корпус.
  - Текущий статус в реальном времени: *«Свободна»* (зелёный индикатор) или *«Идёт пара: Черчение (Ж-12) до 12:15»* (синий индикатор).
  - При тапе — подробная почасовая сетка занятий в этом кабинете.

### 5.4. Экран «Преподаватели»
- Поиск преподавателя по ФИО.
- Алфавитный список преподавателей с перечнем дисциплин.
- При тапе — персональное расписание преподавателя на все дни с указанием групп и аудиторий.

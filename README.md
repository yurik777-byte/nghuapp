# 🎨 NGHU Timetable (Расписание занятий НГХУ)

[![Platform: Android](https://img.shields.io/badge/Platform-Android_26%2B-brightgreen.svg?logo=android)](https://developer.android.com)
[![Kotlin](https://img.shields.io/badge/Kotlin-2.0.20-blue.svg?logo=kotlin)](https://kotlinlang.org)
[![Jetpack Compose](https://img.shields.io/badge/UI-Jetpack_Compose_Material_3-blueviolet.svg?logo=jetpackcompose)](https://developer.android.com/jetpack/compose)
[![Backend](https://img.shields.io/badge/Backend-Node.js_24_•_Express_5_•_TypeScript-informational.svg?logo=node.js)](https://nodejs.org)
[![Offline-First](https://img.shields.io/badge/Storage-Room_SQLite_2.6-success.svg?logo=sqlite)](https://developer.android.com/training/data-storage/room)

Полнофункциональный программный комплекс для студентов и преподавателей **Новосибирского государственного художественного училища (колледжа)** (ГАПОУ НСО «НГХУ»).

Комплекс решает проблему чтения сложных многостраничных PDF-расписаний с официального сайта [nghu.ru/students/timetable/](https://nghu.ru/students/timetable/) и состоит из двух взаимосвязанных частей:
1. **Node.js REST API Scraper (`server/`)**: Автоматический сервис загрузки, координатного парсинга PDF-матриц с расписанием и агрегации данных по группам, аудиториям, корпусам и преподавателям.
2. **Native Android Client (`android/`)**: Нативное мобильное приложение на **Kotlin + Jetpack Compose + Material 3**, спроектированное в дизайне и UX популярного студенческого приложения **«Кампус»** с поддержкой полноценного **офлайн-режима**.

## 🏛 Архитектура комплекса

Проект спроектирован по принципу **Offline-First Clean Architecture**:

```mermaid
flowchart TD
    Site["Сайт nghu.ru\n(PDF-расписание)"] -->|HTTP Scraping| Scraper["Scraper & PDF Parser\n(pdfjs-dist + cheerio)"]
    Scraper -->|Нормализованные данные| Cache["In-Memory Cache &\nAggregators"]
    Cache -->|REST API (JSON)| Express["Express 5 Server\n(Port 3000)"]

    subgraph Android App ["Android Client (Offline-First)"]
        Retrofit["Retrofit 2 + OkHttp\nNetworkClient"]
        Repo["ScheduleRepository"]
        Room[("Room SQLite DB\nLocal Cache")]
        VM["StateFlow ViewModels\n(Schedule, Rooms, Teachers)"]
        UI["Jetpack Compose UI\n(Material 3 / Campus Style)"]

        Express -.->|HTTP / WiFi / 10.0.2.2| Retrofit
        Retrofit -->|DTOs| Repo
        Repo <-->|Reactivity & Persistence| Room
        Room -->|Flow<Data> (0 ms)| Repo
        Repo -->|Domain State| VM
        VM -->|Compose States| UI
    end
```

- **0 мс задержки при старте**: Расписание, аудитории и преподаватели мгновенно читаются из локальной базы данных **Room SQLite**.
- **Фоновая реактивная синхронизация**: При наличии сети мобильное приложение обновляет данные с сервера через **Retrofit 2 / Kotlinx Serialization** и атомарно актуализирует кеш SQLite.
- **Отказоустойчивость**: При отсутствии сети приложение продолжает работу в автономном режиме с отображением ненавязчивого баннера *«Офлайн-режим • Отображаются сохранённые данные»*.

## 🚀 Быстрый старт: Сервер (Backend)

Сервер находится в каталоге `server/` и написан на TypeScript под платформу Node.js.

### Требования
- **Node.js**: версия 20.x или 24.x (проверено на Node 24.19.0).
- **npm**: версия 10.x или выше.

### Установка зависимостей
Откройте терминал в каталоге сервера и выполните установку:
```bash
cd server
npm install
```
*(На Windows PowerShell можно использовать `npm.cmd install`)*.

### Запуск в режиме разработки
Запуск сервера с автоматической перезагрузкой при изменении исходного кода (`tsx watch`):
```bash
npm run dev
```
По умолчанию сервер запустится на порту `3000`:
```text
NGHU Timetable Server running on port 3000
```

### Сборка и продакшен-запуск
Компиляция TypeScript в каталог `dist/` и запуск:
```bash
npm run build
npm start
```

### Тестирование сервера
Сервер снабжен модульными и интеграционными тестами (разбор реального PDF, проверка корпусов Спартака/Красный, WP-скрапер, эндпоинты API):
```bash
npm test
```
Все **26 тестов** выполняются встроенным тест-раннером Node.js `tsx --test`.

### 📡 Документация REST API

Базовый URL: `http://localhost:3000` (или `http://10.0.2.2:3000` из эмулятора).

| Метод | Эндпоинт | Параметры (Query) | Описание |
|---|---|---|---|
| `GET` | `/health` | — | Проверка здоровья сервера и текущего времени |
| `GET` | `/api/meta` | — | Метаданные расписания (семестр, период действия, дата обновления) |
| `GET` | `/api/schedule` | `group` *(str)*, `date` *(YYYY-MM-DD)* | Полное расписание или фильтрация по конкретной группе/дате |
| `GET` | `/api/groups` | — | Список всех 24 учебных групп с указанием курса (1..4) и отделения |
| `GET` | `/api/rooms` | `building` *(main\|spartaka)*, `date`, `time` *(HH:MM)* | Список аудиторий с вычислением статуса занятости в реальном времени |
| `GET` | `/api/teachers` | `name` *(str)*, `teacher` *(str)* | Каталог преподавателей с дисциплинами и персональными сетками занятий |
| `POST` | `/api/refresh` | — | Принудительное скачивание и парсинг свежего файла с сайта училища |

#### Примеры запросов:

- **Получить расписание группы Д-11:**
  ```bash
  curl http://localhost:3000/api/schedule?group=Д-11
  ```

- **Получить занятость кабинетов Главного корпуса (Красный пр-т, 9):**
  ```bash
  curl "http://localhost:3000/api/rooms?building=main&date=2026-09-04&time=10:00"
  ```
  Пример ответа:
  ```json
  [
    {
      "room": "101",
      "building": "main",
      "buildingAddress": "Красный пр-т, 9",
      "status": "occupied",
      "currentLesson": {
        "subject": "Живопись",
        "group": "Ж-11",
        "teacher": "Кузнецов А. В.",
        "timeStart": "09:00",
        "timeEnd": "10:35"
      },
      "nextLesson": null,
      "schedule": [ ... ]
    }
  ]
  ```

- **Поиск расписания преподавателя:**
  ```bash
  curl "http://localhost:3000/api/teachers?name=Иванов"
  ```

Проект Android-приложения расположен в каталоге `android/`.

4. Дождитесь завершения автоматического процесса **Gradle Sync**. Обертка Gradle Wrapper (`gradle-8.9-bin.zip`) автоматически загрузит требуемые зависимости.

### 🌐 Настройка сети (Эмулятор vs Реальное устройство)

В файле [`NetworkClient.kt`](file:///android/app/src/main/java/ru/nghu/timetable/data/remote/NetworkClient.kt) настроена точка входа сетевого слоя:

```kotlin
object NetworkClient {
    const val DEFAULT_BASE_URL = "http://10.0.2.2:3000/"
    // ...
}
```

> [!NOTE]
> В манифесте приложения (`AndroidManifest.xml`) установлен флаг `android:usesCleartextTraffic="true"`, что позволяет безопасно тестировать локальный HTTP-трафик без необходимости настройки SSL-сертификатов.

#### Вариант 1: Запуск на официальном Android Emulator (По умолчанию)
- **Никаких изменений не требуется!**
- Внутри эмулятора Android адрес `10.0.2.2` является специальным псевдонимом обратной петли (loopback) к `127.0.0.1` вашего хост-компьютера.
- Просто запустите бэкенд (`cd server && npm run dev`), затем нажмите кнопку **Run 'app'** (зелёный треугольник) в Android Studio.

#### Вариант 2: Запуск на физическом смартфоне через USB (Рекомендуемый для отладки)
Если ваш телефон подключен к компьютеру по USB-кабелю с включенной «Отладкой по USB»:
1. Выполните в терминале команду перенаправления портов Android Debug Bridge:
   ```bash
   adb reverse tcp:3000 tcp:3000
   ```
2. Теперь сервер вашего ПК доступен на телефоне как `http://127.0.0.1:3000/`. При желании можно указать этот адрес в `NetworkClient.DEFAULT_BASE_URL` или оставить стандартный маппинг.

#### Вариант 3: Запуск на физическом смартфоне по Wi-Fi (Локальная сеть)
Если телефон и компьютер подключены к одному Wi-Fi роутеру:
1. Узнайте локальный IP-адрес вашего компьютера:
   - В Windows PowerShell выполните:
     ```powershell
     ipconfig
     ```
   - Найдите строку `IPv4-адрес` (например, `192.168.1.50`).
2. В файле [`NetworkClient.kt`](file:///android/app/src/main/java/ru/nghu/timetable/data/remote/NetworkClient.kt) обновите константу:
   ```kotlin
   const val DEFAULT_BASE_URL = "http://192.168.1.50:3000/"
   ```
   *(Или вызовите `NetworkClient.updateBaseUrl("http://192.168.1.50:3000/")`)*.
3. Убедитесь, что Брандмауэр Windows (Windows Defender Firewall) разрешает входящие подключения к порту 3000.

## ✨ Ключевые возможности и гид по экранам (Кампус UX)

Приложение воспроизводит эстетику и эргономику популярного студенческого сервиса **«Кампус»**:

### 1. Экран «Расписание» (ScheduleScreen)
- **Селектор учебной группы**:
  - Наверху расположена плашка текущей группы (например, `Группа Д-11 ▾`).
  - Нажатие открывает модальную шторку `GroupPickerBottomSheet` с чипами фильтрации по курсам (1..4) и мгновенным поиском по всем отделениям: *Живопись* (Ж), *Дизайн* (Д), *Театрально-декорационное* (Т).
  - Выбранная группа сохраняется локально.
- **Интерактивная лента дней (`DaySelector`)**:
  - Горизонтальная лента с днями недели (ПН, ВТ, СР, ЧТ, ПТ, СБ) и календарными числами.
  - Текущий день недели выделен контрастным индикатором «Сегодня».
- **Живой виджет текущей пары (`LiveIndicator`)**:
  - Во время учебных часов в верхней части экрана отображается карточка в реальном времени:
    - *«Идёт 2 пара: Живопись (каб. 109) • До конца пары 20 минут»* с плавной полосой прогресса.
  - Во время перемены:
    - *«Перерыв до 13:00 • Осталось 15 минут»*.
    - Если следующая пара проходит в другом здании, отображается специальное предупреждение: *«Переход между корпусами! Красный пр-т, 9 → ул. Спартака, 12»*.
  - До начала занятий / после их окончания отображаются дружелюбные статусы дня.
- **Карточки занятий (`LessonCard`) & Перерывы (`BreakCard`)**:
  - Левая колонка с номерами звонков и таймлайн-линией (статусы: завершена, активна прямо сейчас, предстоит).
  - Цветные маркеры категории предмета (спец. рисунок/живопись, профильный дизайн, общеобразовательные).
  - Четкое разделение корпусов с помощью цветных бейджей:
    - 🏢 **Главный корпус (Красный пр-т, 9)** — классический сине-серый бейдж.
    - 🏛️ **Корпус на ул. Спартака, 12** — контрастный терракотово-оранжевый бейдж, предотвращающий ошибки студентов со зданиями.

### 2. Экран «Аудитории» (RoomsScreen)
- **Быстрый поиск**: Находите кабинеты по номеру, названию дисциплины, фамилии преподавателя или группе.
- **Фильтр по корпусам**: Фильтр-чипы `Все`, `Главный корпус`, `Спартака 12` с бейджами количества кабинетов.
- **Сводка занятости**: Наглядная строка со счетчиками: *Свободно* (зеленый) и *Занято* (красный).
- **Карточка аудитории**:
  - Индикатор статуса: *«Свободна»* или *«Занята: Анатомический рисунок (Ж-21)»*.
  - Раскрывающийся список (*Expandable*): нажмите на карточку, чтобы просмотреть почасовое расписание этого кабинета на весь текущий день.

### 3. Экран «Преподаватели» (TeachersScreen)
- **Алфавитный каталог**: Преподаватели разбиты на разделы с крупными буквенными маркерами (А, Б, В...).
- **Поиск**: Мгновенная фильтрация как по имени педагога, так и по названию предмета (например, введите *«История»* или *«Цветоведение»*).
- **Карточка преподавателя**:
  - Круглый аватар с инициалами в фирменных цветах.
  - Список преподаваемых дисциплин в виде компактных тегов.
  - Раскрывающаяся персональная сетка занятий педагога по всем группам училища с указанием аудиторий и корпусов.

### 4. Навигация и системное поведение
- Нижняя панель навигации Material 3 `NavigationBar` с плавным переходом `Crossfade` между разделами.
- **Умная обработка кнопки «Назад» (BackHandler)**: При нажатии системной кнопки «Назад» на вкладках «Аудитории» или «Преподаватели» приложение возвращается на главный экран «Расписание», предотвращая случайный выход.

## 🛠 Технологический стек

### Мобильный клиент (Android)
- **Язык**: Kotlin 2.0.20
- **Интерфейс**: Jetpack Compose (BOM 2024.09.00), Material Design 3, Material Icons Extended
- **Архитектура**: MVVM, Unidirectional Data Flow, Clean Architecture
- **Локальная база данных**: AndroidX Room 2.6.1 + KSP
- **Сетевой стек**: Retrofit 2.11.0, OkHttp 4.12.0 Logging Interceptor
- **Сериализация**: Kotlinx Serialization JSON 1.7.2
- **Асинхронность**: Kotlin Coroutines 1.8.1, StateFlow, SharedFlow
- **Жизненный цикл**: Lifecycle Runtime Compose & ViewModel Compose 2.8.5

### Бэкенд (Server)
- **Среда выполнения**: Node.js 24+
- **Язык**: TypeScript 7.0+
- **Веб-фреймворк**: Express 5.2 (с поддержкой CORS и JSON body-parser)
- **Парсинг PDF**: `pdfjs-dist` 6.3 (координатное извлечение текстовых блоков колонок и строк)
- **Скрапинг HTML**: `cheerio` 1.2
- **Выполнение и тесты**: `tsx` (TypeScript Execute & Node.js Test Runner)
